# AI NPC System Architecture Documentation / AI NPC 系统架构文档

## 1. Overview / 概述

This documentation details the implementation of the "Fast & Slow" AI system, designed to separate immediate physiological reactions from complex social cognition.
本文档详细介绍了“快慢系统”AI 架构的实现。该设计旨在将即时的生理反应与复杂的社会认知分离。

### Core Philosophy / 核心理念
- **Fast System (Physiological)**: Handles survival, immediate reactions, and filtering. Pure C++ logic.
- **Slow System (Social & Cognitive)**: Handles dialogue, memory, and long-term reflection. LLM-based.
- **快系统（生理层）**：处理生存、即时反应和过滤。纯 C++ 逻辑。
- **慢系统（社会与认知层）**：处理对话、记忆和长期反思。基于 LLM。

## 2. Key Data Structures / 核心数据结构

### FSemanticEvent (Source: `Social/SocialTypes.h`)
The standard data packet flowing through the system.
贯穿整个系统的标准数据包。

| Field | Type | Description |
|-------|------|-------------|
| `Instigator` | `AActor*` | Who did it? (谁做的) |
| `Verb` | `FGameplayTag` | What happened? (e.g., `Social.Conflict.Insult`) |
| `Target` | `AActor*` | To whom? (对谁做的) |
| `Content` | `FString` | Natural language description ("A hit B"). |
| `Magnitude` | `float` | Intensity (0.0 - 1.0). |

### FSmartObjectSemantics (Source: `Social/SocialTypes.h`)
Configuration data on assets (Smart Objects).
配置在资产（Smart Objects）上的“自我描述”数据。

| Field | Type | Description |
|-------|------|-------------|
| `SocialTag` | `FGameplayTag` | The meaning of interaction (e.g., `Activity.Rest`). |
| `DescriptionTemplate` | `FString` | Template string ("{Instigator} sits on {Target}"). |
| `Intensity` | `float` | Base intensity. |

## 3. Component Architecture / 组件架构

### A. The World: SmartObjectComponent
**Role**: Allows objects to describe themselves semantically.
**职责**：让物体具备语义自述能力。

- **Config**: Designers set `Semantics` in the Editor.
- **Interface**: Implements `ISmartObjectInterface` for backward compatibility.
- **配置**：策划在编辑器中设置 `Semantics`。
- **接口**：实现了 `ISmartObjectInterface` 以兼容旧系统。

### B. The Nervous System: SensoryComponent
**Role**: Perceives the world and translates raw interactions into Semantic Events.
**职责**：感知世界，将原始交互转化为语义事件。

- **`HandleSmartObjectInteraction`**:
  - Reads `FSmartObjectSemantics` from the target.
  - Generates `FSemanticEvent`.
  - Parses text templates (replays `{Name}`).
- **`ProcessEventFilter` (The Spinal Cord)**:
  - Filters out "Mundane" noise or distant events based on rules.
- **Output**: Broadcasts `OnSemanticEventSensed`.

### C. The Brain: MemoryComponent
**Role**: Stores comprehensive records and manages retrieval.
**职责**：存储完整记录并管理检索。

- **Storage (`CommitEvent`)**:
  - Appends event to `MemoryStream`.
  - Calculates `ImportanceScore` using heuristics (Danger > Conflict > Mundane).
  - Accumulates importance to trigger "Reflection".
- **Retrieval (`RetrieveRelevantMemories`)**:
  - Returns Top N memories based on: $Score = Recency + Importance + Relevance$.
- **Reflection (`ConsolidateMemories`)**:
  - Stores high-level insights generated by LLM as new long-term memories.

### D. The Mind: CognitionComponent
**Role**: Interfaces with LLM for social reasoning.
**职责**：与 LLM 交互进行社会推理。

- **`ProcessStimulus`**:
  - Calls `Memory->RetrieveRelevantMemories`.
  - Constructs a context-rich Prompt using retrieval results.
  - Sends to LLM.
- **`StartDreaming`**:
  - Dumps recent memories.
  - Asks LLM to summarize/reflect.
  - Calls `Memory->ConsolidateMemories` with results.

### E. The Controller: UtilityAIController
**Role**: Wiring everything together.
**职责**：将所有组件连接起来。

- **Wiring**: Binds `Sensory->OnSemanticEventSensed` to `Memory->CommitEvent`.
- **Timer**: Runs a "Dreaming" cycle every 5 minutes to trigger reflection.

## 4. Data Flow Example / 数据流示例

1. **Interaction**: NPC sits on a Chair.
   - **交互**：NPC 坐在一把椅子上。
2. **SmartObject**: Chair provides Semantics (`Activity.Rest`, "{Instigator} rests.").
   - **智能物体**：椅子提供语义数据。
3. **Sensory**: `SensoryComponent` creates Event (`Instigator=NPC`, `Verb=Activity.Rest`).
   - **感官**：创建事件。
4. **Filter**: Passed (Importance > Threshold).
   - **过滤**：通过。
5. **Memory**: Event stored in `MemoryStream`.
   - **记忆**：存入记忆流。
6. **Cognition** (Optional/Timer): LLM reads this memory later to decide "I feel rested".
   - **认知**：LLM 稍后读取此记忆，判定“我感觉休息好了”。

## 5. Usage Guide / 使用指南

### How to add a new Interactive Object (如何添加新交互物体)
1. Add `SmartObjectComponent` to your Actor Blueprint.
   - 在 Actor 蓝图中添加 `SmartObjectComponent`。
2. Configure `Semantics` property:
   - Sets **Tag** (e.g., `Social.Greet`).
   - Sets **Template** (e.g., "{Instigator} greets {Target}").
   - 设置语义属性。

### How to add a new Social Rule (如何添加新社交规则)
1. Add a new `GameplayTag` in `SocialGameplayTags.h` (C++).
   - 在 C++ 中添加新的 Tag。
2. Update `MemoryComponent::CalculateImportance` to define its base score.
   - 更新计算分数的逻辑。

### How to debug (如何调试)
- **Log**: Filter output Log by `LogTemp` or `AINPC`.
  - **日志**：查看输出日志。
- **Dump Memory**: Call `MemoryComponent->DumpMemoryLog()` to see what the NPC remembers.
  - **查看记忆**：调用 `DumpMemoryLog` 查看当前记忆流。
